# LifeVerse MCP installation instructions

The canonical agent-readable installation guide is
[llms-installation.md](llms-installation.md). This compatibility filename is
kept for clients and registries that look for `llms-install.md`.

Connect directly to the hosted Streamable HTTP endpoint:

`https://lifeverse.gufreelancer.com/api/mcp`

No local package, API key, or account is required.
