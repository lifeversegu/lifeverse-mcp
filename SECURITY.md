# Security policy

## Scope

This repository contains public documentation and connection metadata for the
hosted LifeVerse Product Discovery MCP service.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Send a
concise report to `bjwgxx@163.com` with the affected endpoint, reproduction
steps, and impact. Do not include real user data or perform destructive testing.

The service is intentionally read-only and anonymous. Reports involving data
exposure, authorization bypass, request smuggling, denial of service, or a way
to reach non-public LifeVerse data are especially useful.
